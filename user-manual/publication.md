# Lehmer's Mahler Measure Problem

The primary purpose of this repository is to test and improve the [ACME](https://github.com/vtejdn/acme) framework.
It uses Lehmer’s problem as a research case study, drawing on arithmetic, algebraic entropy, group growth, and operator theory.

## Current status

- Partial results. We have established lower bounds for Mahler measure in several structured classes of integer polynomials, using arithmetic, entropy, and operator methods.
- Obstructions. We have identified recurring barriers to extending these results to the general problem, particularly the loss of uniform control as the degree and complexity of the inputs grow.
- Explicit constructions. Recent work has explored candidate counterexample families, clarifying the arithmetic and factorization conditions needed for their Mahler measures to approach one from above.
- Overall status. These investigations have not yet produced a proof or a counterexample to the unrestricted conjecture.
