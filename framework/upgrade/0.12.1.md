# Upgrade to 0.12.1

This note covers upgrading to ACME `0.12.1` from `0.12.0` at the [official 0.12.0 release commit](https://github.com/vtejdn/acme/commit/e8cedc471ebcab91f84e019ea3d4343ce9a63884).

## Changes

- `framework/agent-actions.md`, `framework/rules/identity.md` and `framework/rules/workflow.md` require checking the selected project branch and integrating incoming commits before fixing new material numbers, versions and references for an authorized push.
- The project integration rule coordinates only agents whose active writes or inputs are affected before changing the working copy, and limits subsequent material and reference checks to the affected scope. [Project integration](../rules/identity.md#shared-repository-updates-and-integration)
- Allocation during push preparation and retry accounts for independent issuances in the affected sequences, including unpublished assignments already fixed or committed.
  The agent uses the existing counters, Git evidence and material rules to preserve stable identities, fixed references and provenance. [Allocation](../rules/identity.md#allocation-and-concurrency)
- The delivery rules compare ancestry for an existing target tip and allow an authorized first push when the branch is confirmed absent.
  Defer the push while branch state remains unknown. [Push preparation](../rules/identity.md#push-preparation)
- `framework/rules/computations.md` clarifies that replacement or removal of generated output waits for overlapping readers and writers.
  Separate output paths can be used concurrently.
  A directory with an active reader or writer is not ready for direct clearing. [Computation outputs](../rules/computations.md#computation-output-location) · [Direct clearing](../rules/computations.md#clearing-local-computation-outputs)
- `framework/rules/workflow.md` and `framework/agent-actions.md` clarify that the main research agent steers a complex Task against its original objective, brings branch results together and organizes subagents around decisive gaps.
  At each substantive research round's closeout, the main agent states what advanced or was ruled out, the key remaining gap and why the next work or stop follows, using the existing strategy and handoff. [Research coordination](../rules/workflow.md#research-coordination) · [Round closeout](../rules/workflow.md#exploration-round-closeout)
- The version metadata and the English, Chinese, French, German, Japanese and Spanish manuals identify the current framework version as `0.12.1`. [Version metadata](../version.json) · [User manual](../../user-manual/user-manual.md)

## Additional actions for this version

Ordinary synchronization and bounded merges of local edits suffice. [Installed-framework upgrade procedure](../versioning.md#upgrading-an-installed-framework)
