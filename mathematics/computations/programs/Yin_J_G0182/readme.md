# Testing simultaneous field radicals in the integer Salem families at the first prime 59

<a id="search"></a>
## Finite trace search

For each delay \(55\le n\le58\) and sign \(\epsilon=\pm1\), test whether the exterior root \(r\) of \(G_a=X^{n+1}-aX^n+\epsilon(aX-1)\) has its positive \(59q\)-th root in \(\mathbb Q(r)\) for an integer \(a\ge3\).
At \(q=61\), none of the \(472\) residue, sign and delay choices gives a field radical.
This includes every integer seed \(a\ge3\) in the eight families.
The [seed classification](../../../claims/Yin_C_G0345_v681.md#roots) specifies the linear cofactor removed for each sign and delay.
The [prime radical bound](../../../claims/Yin_C_G0345_v702.md#statement) supplies \(r^{1/59}<59\).

Run the [program](radical_pair.py) with Python from the repository root.
The recorded execution used Python 3.14.3, NumPy 2.4.4 and SymPy 1.14.0.
The parameters and polynomials are generated in the program and all results go to standard output.

~~~

<a id="method"></a>
## Exact arithmetic and the rejection test

Write \(P_a=G_a/U\), where \(U\) has the distinct roots \(\eta\in\{-1,1\}\) satisfying \(\eta^{n-1}=\epsilon\).
If \(\gamma=r^{1/(59q)}\) exists in the field, its monic reciprocal minimal polynomial \(S\) has degree \(d=\deg P_a\).
Reduction modulo 59 and Frobenius give \(\overline S^{[q]}=\overline P_a\), where the superscript raises each root to the indicated power, preserving its multiplicity.
The [finite-field inversion](../../../claims/Yin_C_G0345_v708.md#reduction) applies when \(\operatorname{ord}_q(59)>d\).
Every nonzero root of an irreducible degree-\(f\) factor of \(\overline P_a\) then has a unique \(q\)-th root in \(\mathbb F_{59^f}\).
Conversely a root of a prospective degree-\(d\) polynomial lives in an extension of degree at most \(d\), on which the \(q\)-th power map is bijective.
Inverting there agrees with inversion in the subfield generated by its \(q\)-th power.
The program uses each irreducible factor with its actual multiplicity and raises its residue \(X\) to \(q^{-1}\bmod(59^f-1)\).
It checks its \(q\)-th power, computes its power traces by Newton's identities, and reconstructs the reciprocal modular polynomial.
Powering the full reconstructed polynomial's roots by \(q\) reproduces the target's first \(d/2\) power sums, which determine that reciprocal polynomial because \(d<59\).

For \(1\le j\le d/2<q/2\), the exterior contribution \(\gamma^j\) is less than \(\sqrt{59}<8\), the interior contribution is less than one, and each of the \(d-2\) remaining conjugates has modulus one.
The program allows every integer trace \(|s_j|\le d+7\) with the required residue modulo 59.
The integral Newton coefficient at position \(j\) requires \(j\mid s_j+\sum_{i=1}^{j-1}a_i s_{j-i}\), where \(a_i\) are the earlier coefficients of \(S\).
The [coefficient decoding](../../../claims/Yin_C_G0345_v708.md#decoding) and reciprocal symmetry recover a finite list containing every possible minimal polynomial.
In the NumPy residue-ring arithmetic, convolution entries are at most \(d(59-1)^2\), and the following reduction dot product is at most \((2d-1)d(59-1)^3<2^{31}\) throughout these runs.
Signed 64-bit arithmetic therefore gives exact residues.
Integral coefficient decoding uses Python integers.

The exterior and interior real pair and the neutral complex-conjugate pairs imply \(S(1)<0<S(-1)\).
The program retains the irreducible candidates with these signs.
Put \(E=59q\), and let \(s_j\) now denote the full integer power sums of such a candidate.
If it comes from a seed, the first two power sums of \(G_a\) must be \(a\) and \(a^2\), so
\[
 s_{2E}+\sum_{\eta:U(\eta)=0}\eta^2
   =\left(s_E+\sum_{\eta:U(\eta)=0}\eta\right)^2 .
\]
The program tests this identity by binary modular polynomial powering and the trace functional, at primes \(101,103,107,109,113\) in that order.
A failure at any one modulus excludes every possible seed for that candidate.
The last five integer columns of the program's output count the candidates still passing after each successive modulus.
Any survivors are printed with their seed residue and full polynomial for further examination.

## All 47 primes of order greater than 58 through 410

The following command repeats the eight sign and delay cases for every prime \(59<q\le410\) with \(\operatorname{ord}_q(59)>58\).
It factors each distinct seed polynomial modulo 59 once and reuses the result across primes.
The full run took approximately two minutes and thirty seconds.

~~~
python mathematics/computations/programs/Yin_J_G0182/radical_pair.py --through 410
~~~

The selected primes were
\[
\begin{gathered}
61,71,73,79,89,97,101,107,109,113,131,149,167,173,179,191,\\
199,211,223,227,229,233,239,241,251,257,263,269,271,283,293,307,\\
311,313,317,331,347,349,359,367,373,379,383,389,397,401,409.
\end{gathered}
\]
The program examined \(47\cdot8\cdot59=22{,}184\) residue, sign, delay and prime choices.
It produced \(5{,}640\) complete reciprocal polynomials, of which \(1{,}081\) passed the sign tests and all \(1{,}081\) were irreducible.
For each of the 47 primes the eight individual rows agree with the table above through its irreducibility column.
At the following nine triples \((q,n,\epsilon)\), exactly one candidate per triple satisfied the trace identity modulo 101.
\[
 (71,55,+1),\ (73,55,+1),\ (101,58,-1),\ (149,57,-1),\
 (223,58,+1),\ (269,57,-1),\ (283,58,-1),\ (383,58,-1),\
 (389,55,+1).
\]
All other rows had zero candidates after the first modulus.
Each of these nine failed modulo 103, so every final count was zero.
Thus every indicated pair \(59,q\) is excluded for both signs, all four delays and every integer \(a\ge3\).

The [sixteen remaining primes](exceptional-orders.md#result) are covered by a separate square-modulus and cyclotomic orbit test.
