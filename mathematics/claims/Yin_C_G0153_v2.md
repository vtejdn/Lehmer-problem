## 1. One field lemma for all three pairs

Let L be a characteristic-zero field and a,b,c in L be nonzero.
Define

    e=b^2-a^3, f=2c^2-3a^5, g=c^3-2b^5.              (1)

If e=0, the element v=b/a is nonzero and satisfies v^2=a,v^3=b.
Thus

    e=f=0 => (c/v^5)^2=3/2
             => [2c/v^5]^2=6,
    e=g=0 => (c/v^5)^3=2.                             (2)

These are identities IN L.
There is no assertion that v, c/v^5 or their inverses belong to a particular nonmaximal order.
That order membership is unnecessary for the field obstruction.

If f=g=0, cubing2c^2=3a^5 and squaring c^3=2b^5 gives8c^6=27a^15 and c^6=4b^10.
Hence

    32b^10=27a^15,
    w=2b^2/a^3 satisfies w^5=27,
    eta=w^2/3 satisfies eta^5=3.                      (3)

All displayed divisions are legal because a,b,c are nonzero and the field has characteristic zero.

Each implication is sharp at the level of arbitrary field elements.
If L contains gamma with gamma^2=6, take(a,b,c)=(4,8,16gamma).
These are nonzero and e=f=0, whereas g!=0: g=0 would imply both (c/2^5)^2=3/2 and (c/2^5)^3=2, giving27=32 after sixth powers.
If L contains u with u^3=2, take(a,b,c)=(1,1,u); then e=g=0 and f!=0 for the same reason.
If L contains eta with eta^5=3, take

    (a,b,c)=(2eta,2eta^3,12).

Then3a^5=288=2c^2 and2b^5=1728=c^3, so f=g=0.
Also e=4eta^3(eta^3-2)!=0, since eta^3=2 would give eta^15=32 and27 simultaneously.
These controls can all be taken to consist of algebraic integers in their indicated number fields.
They are NOT claimed to be Frobenius quotients of any actual P.
They prove the exact scope of a field-only obstruction, not actual polynomial coverage or a counterexample to C149.

For a number field L of degree n, the polynomials X^2-6, X^3-2 and X^5-3 are irreducible over Q: they satisfy Eisenstein's criterion respectively at2,2,3.
The needed elementary argument is that if a monic integer polynomial with every nonleading coefficient divisible by p and constant coefficient not divisible by p^2 factored over Q, Gauss's lemma would give monic integer factors; their reductions modulo p would be powers of X, so both constants would be divisible by p, contradicting the constant term.
Applying the tower formula to the subfield generated by the displayed element yields

    e=f=0 =>2 divides n,
    e=g=0 =>3 divides n,
    f=g=0 =>5 divides n.                              (4)

This is the classical Eisenstein mechanism already used in [C135v2's reciprocal realization](Yin_C_G0135_v2.md#reciprocal-parity-class-realization), which explicitly credits [L217's binary-depth/irreducible realization](../ledger/Yin_L_G0217_v1.md#binary-depth-and-irreducible-realization).
Those actual passages apply the same prime-divisibility and constant-term-not-p-squared criterion to an Eisenstein translate.
The present binomials need no translate or CRT construction; no local-depth, root-distribution or realization conclusion from those records is imported.
The complete elementary argument above records this particular application, not a new irreducibility criterion or an enlargement of an external source-proof audit.

There is also a particularly short full proof of the totally-real exclusion.
If L is totally real and u in L has u^3=2, then EVERY embedding sigma:L->C sends u to the unique real root of X^3-2, which is the same as u in the given real embedding.
Consequently Tr_(L/Q)(u)=n u is rational, so u is rational.
This contradicts irreducibility.
The identical argument for eta^5=3 uses the unique real fifth root.
Thus

    L totally real => (e,g)!=(0,0), (f,g)!=(0,0).       (5)

The trace is the sum over ALL n embeddings, with the multiplicities of any smaller own field retained.
No assumption that L is Galois is made.
The quadratic control L=Q(sqrt6) above shows why total reality alone does not imply the corresponding (e,f) exclusion.
