# A discriminant test and finite exterior minima for the five-term prime family

<a id="statement"></a>
## A computable test for quadratic subfields of low-measure units

Let \(w\) be an algebraic unit of degree \(2n\) whose field contains a quadratic number field \(D\) of fundamental discriminant \(d_D\).
Then
\[
                         |d_D|\le4n^2 M(w)^{4-2/n}.               \tag{1}
\]
In particular, when the [quadratic twist criterion](Yin_C_G0345_v316.md#twists) requires \(D=\mathbb Q(\sqrt\Delta)\) for a given nonzero integer \(\Delta\), a unit with \(M(w)\le A\), \(A>1\), is excluded if the positive squarefree kernel of \(|\Delta|\) exceeds \(4n^2 A^4\).
This test requires no integer factorization.

For the irreducible [five-term polynomial](Yin_C_G0345_v306.md#statement)
\[
                 P_p(z)=z^{2p}-z^{p+1}-z^p-z^{p-1}+1,
\]
\(M(P_p)<13/10\) for every prime \(p\ge11\).
Also \(M(P_5)<13/10\) and \(M(P_7)<33/25\); all these upper bounds are below the plastic number.
For every prime \(5\le p\le251\), the exact minimum exterior count of nontorsion units with a positive power in the splitting field and \(M(y)\le M(P_p)\) is
\[
                         1+2\lfloor p/6\rfloor.                   \tag{2}
\]
The input realizes it.
The height estimate for \(p>251\) is analytic, whereas the discriminant exclusions here concern only the finite range in (2).

<a id="discriminant"></a>
## The discriminants of a field, a generator and its quadratic subfield

Since \([\mathbb Q(w):D]=n\), the tower formula shows that \(d_D^n\) divides the discriminant of the unit's field.
The latter divides the discriminant of the monic integral minimal polynomial, by the index-square formula.
In the Vandermonde matrix on the \(2n\) conjugates, the row at \(z\) has Euclidean norm at most \(\sqrt{2n}\max(1,|z|)^{2n-1}\).
Hadamard's inequality and squaring bound the polynomial discriminant by \((2n)^{2n}M(w)^{4n-2}\).
Taking the \(n\)-th root gives (1).
The absolute fundamental discriminant of \(\mathbb Q(\sqrt\Delta)\) is at least the positive squarefree kernel of \(|\Delta|\).
For integer \(B\), that kernel exceeds \(B\) if and only if \(|\Delta|/s\) is a nonsquare or nonintegral for every \(1\le s\le B\).

<a id="uniform"></a>
## A strict subplastic bound at every index

Put \(I=\pi^{-1}\int_0^{\pi/3} f(u)\,du\), where \(f(u)=\operatorname{arcosh}(1/2+\cos u)\).
This is the [two-variable limit](Yin_C_G0345_v306.md#limit).
Apply the [one-sided specialization inequality](Yin_C_G0345_v161.md#statement) with \(H=p\), \(N=1\), and \(F(X,Y)=X+X^{-1}-1-Y-Y^{-1}\), of width two in \(Y\).
It gives \(\log M(P_p)\le I+2\log2/p\).
On \([0,\pi/3]\), \(f\) is concave as a composition of an increasing concave function and a concave function.
On each of four equal intervals its midpoint value is an upper bound for its mean.
Upper bounds for those four values, in increasing order of angle, are \(0.956,0.892,0.750,0.466\).
The following rational inequalities verify them, using \(\pi>157/50\), the decreasing cosine, its alternating expansion, and the positive expansion for \(\cosh\).
They also verify \(I+2\log2/251<\log(13/10)\) using \(\log2<7/10\) and a lower alternating sum for the right-hand side.

~~~python
from fractions import Fraction as Q
from math import factorial
bounds = [Q(a,1000) for a in (956,892,750,466)]
for j,b in enumerate(bounds):
    v = Q(157*(2*j+1),1200)
    cos_upper = sum((-1)**k*v**(2*k)/factorial(2*k) for k in range(5))
    cosh_lower = sum(b**(2*k)/factorial(2*k) for k in range(4))
    assert cosh_lower>Q(1,2)+cos_upper
a = Q(3,10)
log_lower = a-a*a/2+a**3/3-a**4/4
assert sum(bounds)/12+Q(14,10*251)<log_lower
assert sum(Q(7,10)**k/factorial(k) for k in range(5))>2
~~~

The smaller indices are checked below by root squaring with an integer coefficient norm bound.
For \(f(z)=E(z^2)+zO(z^2)\) of even degree, its root-squared polynomial is \(E(z)^2-zO(z)^2\).
Indeed the product \(f(u)f(-u)\) equals that specialization at \(z=u^2\).
Monicity persists and the new Mahler measure is the square of the previous one.
For the iterate \(f_j\), Parseval and Jensen give \(M(P_p)^{2^{j+1}}\le\sum |[z^k]f_j|^2\).
Thus all comparisons to rational cutoffs in the computation have integer certificates.
Finally \((33/25)^3-33/25-1<0\), and the polynomial defining the plastic number is increasing above one.

<a id="finite"></a>
## Exact minima through prime 251

Write \(Q_p=C_p-X-1\), with \(C_p(z+z^{-1})=z^p+z^{-p}\).
For \(p>23\), the [five-term character calculation](Yin_C_G0345_v316.md#five-term) gives \(R=1\), \(c=\lfloor p/6\rfloor\).
For \(p\equiv1\bmod4\), the measure-constrained minimum is already \(2c+1\).
For \(p\equiv3\bmod4\), a smaller count requires an actual unit of degree \(2p\) whose field contains \(D=\mathbb Q(\sqrt{\operatorname{disc} Q_p})\).
The discriminant here may be computed from the polynomial even when its index in the ring of integers is nontrivial.
The two discriminants differ by a positive integer square.
Every output in the budget is reciprocal by [Smyth's strict nonreciprocal bound](../audits/literature/Smy71/Yin_U001.md#smy71-u001).

For completeness, the same group and twist arguments apply to the primes \(7,11,13,17,19,23\).
The trace-root count in [the five-term proof](Yin_C_G0345_v316.md#five-term) is valid for these primes, with \(0<c<(p-1)/4\) and \(R=1\).
In degrees \(7,13,17,19\), [the full-cycle classification](../audits/literature/Jo13/Yin_U001.md#full-cycle-classification) has no exceptional simple-group entry.
In degrees \(11\) and \(23\) the involution has respectively one and three transpositions.
The [exceptional actions](../audits/literature/Jo13/Yin_U001.md#small-degree-even) of \(L_2(11),M_{11},M_{23}\) contain only even permutations, as is also seen directly from their standard generators.
None contains that odd involution.
The fixed-point argument for the affine and projective entries applies in these degrees to every transitive stabilizer image as well as to the original group.
Thus [the small-support proof](Yin_C_G0345_v315.md#stabilizers) applies verbatim to the involution here.
The sign calculations use simplicity of \(A_{p-1}\) and transitivity on pairs, valid already for \(p\ge7\).
The fixed set has size at least five; the signature is mixed and \(2c+1<\min(4c,(p+1)/2)\).
These are the hypotheses for the [stabilizer characters and twist field](Yin_C_G0345_v316.md#characters).
At \(p=5\) there is exactly one exterior conjugate: on the trace interval the two feasible positive peaks each supply two neutral traces by the same crossing proof (the interval meeting \(\pi/3\) is increasing there).
The input attains one and a nontorsion unit must have an exterior conjugate by Kronecker's theorem.

The integer computation below tests all 52 primes from 5 through 251.
At the 28 primes with \(p\equiv3\bmod4\) it tests (1) with the weaker common cutoff \(33/25\), by ruling out every positive squarefree kernel up to the displayed bound.
Only operations on integers and rational integer polynomials are used.
The coefficient-norm test gives the stronger \(13/10\) bound throughout the finite range except at 7, completing the uniform estimate above.

~~~python
from math import isqrt
from sympy import Poly, ZZ, primerange, symbols

z = symbols("z")
Z = Poly(z, z, domain=ZZ)
one = Z**0

def trace_polynomial(p):
    last, current = 2*one, Z
    for _ in range(2,p+1):
        last, current = current, Z*current-last
    return current-Z-one

def below_threshold(p, top, bottom):
    f = Z**(2*p)-Z**(p+1)-Z**p-Z**(p-1)+one
    denominator = 2
    for j in range(16):
        if j >= 8:
            square_length = sum(int(a)**2 for a in f.all_coeffs())
            if square_length*bottom**denominator < top**denominator:
                return j
        ev, od = {}, {}
        for (k,), a in f.terms():
            (od if k%2 else ev)[(k//2,)] = a
        f = Poly.from_dict(ev,z,domain=ZZ)**2-Z*Poly.from_dict(od,z,domain=ZZ)**2
        denominator *= 2
    raise AssertionError(p)

def excludes_small_squareclass(p):
    disc = abs(int(trace_polynomial(p).discriminant()))
    limit = 4*p*p*33**4//25**4
    return all(disc%s or isqrt(disc//s)**2 != disc//s
               for s in range(1,limit+1))

tested = list(primerange(5,252))
rounds = [below_threshold(p,33,25) if p==7 else below_threshold(p,13,10) for p in tested]
odd = [p for p in tested if p%4 == 3]
assert len(tested)==52 and max(rounds)<=15
for p in odd:
    assert excludes_small_squareclass(p), p
assert len(odd)==28
~~~
