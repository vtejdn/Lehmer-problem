# Genuine terminal intervals and the missing endpoint value

This bounded research test was carried out for Yin's [G0001 investigation](../tasks/Yin_T_G0001_v1.md#contract) on 2026-11-09.
It continues the [quadratic localization and diagonal models](Yin_L_G0464_v14.md#exact-models), using the fixed conductor \(p=19683\), \(n=9841\), and cut \(k=1990\).
Only the residual triple \((O,V,W)=(10,18,27)\), with the fixed double atom \(s=-15/16\), was tested.
The mathematical distinction is between a fractional occupancy and a genuine indicator of root-to-pole intervals.
The test certifies such a genuine interval configuration for all seven polynomial trace equations, but its endpoint value satisfies \(0.022<U<0.023\), so it fails the original requirement \(U=1\).
It neither constructs an integer input nor establishes feasibility of the other four residual triples.
The derivation and computation here are author work; independent review and any Claim adoption are separate.

<a id="oriented-geometry"></a>
## Correctly oriented root-to-pole intervals

Write the poles in increasing order by
\[
 x_0=-2,\qquad x_i=b_{n+1-i}\quad(1\le i\le n),\qquad
 c=x_{k+1}=b_{7851},\qquad k+1=1991.
\]
The [complete-root pairing](../claims/Yin_C_G0882_v8.md#statement) chooses one root \(u_i\) in each cell \((x_{i-1},x_i)\) except the sign-changing cell \(i=k+1\).
The first cell is the strict left-endpoint interval; the omitted cell is between the largest negative-residue pole and the smallest positive-residue pole.
Each chosen root is paired with its cell's right pole.
Thus the actual occupancy is
\[
 w(t)=\sum_{i\ne k+1}\mathbf1_{[u_i,x_i]}(t),
 \qquad x_{i-1}<u_i<x_i.
 \tag{1}
\]
The allowed cells are disjoint, the cut cell is empty, and \(w\) is zero on \((x_n,2]\).
Within an allowed cell it must be a terminal interval indicator, not an arbitrary measurable subset or a fractional constant.

For two remaining traces \(a,b\) and the trace-difference functional \(\mathcal D\), the exact identity is
\[
 \mathcal D(f)+f(c)=f(a)+f(b)-\int_{-2}^2w(t)f'(t)\,dt.
 \tag{2}
\]
With \(D_j=\mathcal D(t^j)\) and lengths \(\ell_i=x_i-u_i\), the seven nonconstant equations are the finite nonlinear system
\[
 \sum_{i\ne k+1}\bigl(x_i^j-(x_i-\ell_i)^j\bigr)
       =a^j+b^j-c^j-D_j,\qquad 1\le j\le7,
 \qquad0<\ell_i<x_i-x_{i-1}.
 \tag{3}
\]
These equations specify actual selected roots and are stronger than replacing (1) by \(0\le w\le1\).

<a id="terminal-support"></a>
## A sharper linear-test bound than negative variation

For a real polynomial \(f\), define
\[
 \mathcal B(f)=\sum_{i\ne k+1}
       \left(\max_{[x_{i-1},x_i]}f-f(x_i)\right).
\]
Each summand is nonnegative because the right endpoint is included in its maximum.
It is the exact maximum of \(f(u_i)-f(x_i)\) over the closed cell, and also the supremum over its open interior.
The choices in separate cells are independent, so \(\mathcal B(f)\) is the exact support bound for the paired contribution.
Consequently every actual configuration satisfies
\[
 \operatorname{Re}f(a)+\operatorname{Re}f(b)
       \ge\mathcal D(f)+f(c)-\mathcal B(f).
 \tag{4}
\]
For any \(u\le x_i\) in a cell,
\[
 f(u)-f(x_i)=-\int_u^{x_i}f'(t)\,dt
       \le\int_{x_{i-1}}^{x_i}\max(0,-f'(t))\,dt.
\]
Summing over allowed cells proves \(\mathcal B(f)\le V_-(f)\).
This improvement is not already contained as an equality in the previous negative-variation bound.
For example, \(f(t)=-t\) has \(V_-(f)=4\), whereas
\[
 \mathcal B(-t)=x_n+2-(x_{k+1}-x_k)<4.
\]
The omitted cut cell and the unused interval above the largest pole already give a strict difference at degree one.
The full nonlinear system (3) additionally requires a single configuration to work simultaneously for all polynomial tests; separate support inequalities do not assert that simultaneous realization.

<a id="fixed-parameterization"></a>
## One fixed seven-parameter family of genuine intervals

The chosen trace differences are exactly those of [C882v8](../claims/Yin_C_G0882_v8.md#diagonal-statement) at \((10,18,27)\):
\[
            (D_0,\ldots,D_7)=(1,-2,-2,-2,-10,-2,-32,-9).
\]
Use \(a=b=s=-15/16\) and the actual algebraic cut \(c=x_{1991}\), not its rational midpoint.
The coarse cells have endpoints \(y_j=-2+j/64\), \(0\le j\le256\).
Let \(A_\theta(t)\) be the coarse step function with the following values:

- Value one on coarse-cell indices 66 through 109, 160 through 220, and 254 through 255, with every range inclusive.
- Seven free values \(\theta_1,\ldots,\theta_7\) on indices \((0,65,110,112,159,221,253)\), respectively.
- Value zero on every other coarse cell.

These are the fixed coarse columns of the earlier diagonal certificate, used only to define a bounded parameterization.
They are not themselves interpreted as actual root intervals.
Fix \(\eta=2^{-20}\).
For each allowed actual cell define
\[
 \ell_i(\theta)=\eta(x_i-x_{i-1})
 +(1-2\eta)\int_{x_{i-1}}^{x_i}A_\theta(t)\,dt,
 \qquad u_i(\theta)=x_i-\ell_i(\theta).
 \tag{5}
\]
Each integral is affine in \(\theta\), with coefficients equal to actual overlaps between a pole cell and the specified coarse cells.
For every \(\theta\in[0,1]^7\), its value lies between zero and the cell length.
Therefore
\[
 \eta(x_i-x_{i-1})\le\ell_i(\theta)
       \le(1-\eta)(x_i-x_{i-1}),
\]
which places all 9840 selected roots strictly inside their own cells.
No length or root is assigned to cell 1991.

Let \(T_j(z+z^{-1})=z^j+z^{-j}\), and define the seven polynomial equations
\[
 \Phi_j(\theta)=\sum_{i\ne1991}
       \bigl(T_j(x_i)-T_j(u_i(\theta))\bigr)
       -\bigl(2T_j(s)-T_j(c)-\mathcal D(T_j)\bigr),
 \qquad1\le j\le7.
 \tag{6}
\]
Each \(u_i\) is affine in \(\theta\), so these are degree-at-most-seven polynomial equations with fixed real algebraic coefficients.
Their Jacobian has the exact entries
\[
 \frac{\partial\Phi_j}{\partial\theta_r}
   =(1-2\eta)\sum_{i\ne1991}T_j'(u_i(\theta))
          \left|[x_{i-1},x_i]\cap[y_{f_r},y_{f_r+1}]\right|,
\]
where \(f_r\) is the corresponding free coarse index.
This formula keeps the terminal orientation and the cut omission explicitly.

<a id="existence-certificate"></a>
## Fixed ball-arithmetic certificate of exact existence

The [native J151 program](../computations/programs/Yin_J_G0151/terminal_intervals.py) retains the dyadic center \(\widehat\theta\) and rational preconditioner \(A\), each with denominator \(2^{40}\).
The center numerators are
\[
 (349236363733,787334542439,560980995009,641270727983,
   260181169280,989387092080,829862555069).
\]
The seven rows of the preconditioner are retained in the same fixed native file.
The only parameter box is \(X=\widehat\theta+[-r,r]^7\), \(r=2^{-16}\), and the verifier checks \(X\subset(0,1)^7\).
All poles, overlaps, residuals and Jacobian entries are enclosed at a fixed 128-bit precision using the installed FLINT real-ball arithmetic.
The exactly rational pole \(b_{6561}=-1\) is inserted exactly so that coarse-boundary comparisons do not rely on rounding.
Every other overlap branch and the strict ordering of the poles are verified by interval comparisons.

Write
\[
 \delta=\|A\Phi(\widehat\theta)\|_\infty,\qquad
 q\ge\sup_{\theta\in X}\|I-A\Phi'(\theta)\|_\infty.
\]
The actual outward enclosures gave an upper bound for \(\delta\) approximately \(3.264635\times10^{-12}\) and an upper bound for \(q\) approximately \(1.470780\times10^{-5}\).
The native comparison verifies \(q<1\) and \(\delta+rq<r\) directly with ball bounds; the displayed decimals are not substituted for those comparisons.
No radius or precision enlargement was used.

Here is why the finite certificate establishes exact existence, rather than a small numerical residual.
For \(G(\theta)=\theta-A\Phi(\theta)\), the Jacobian bound implies \(\|G(\theta)-G(\zeta)\|_\infty\le q\|\theta-\zeta\|_\infty\) throughout the convex box.
Also \(\|G(\theta)-\widehat\theta\|_\infty\le\delta+rq<r\), so \(G\) maps the box into itself.
Starting from any point in the box, the iterates have successive differences bounded by a geometric sequence with ratio \(q<1\).
They converge in the closed box to a fixed point by the Cauchy criterion, and continuity gives \(A\Phi(\theta_*)=0\).
The same defect bound implies \(A\Phi'(\widehat\theta)\) is nonsingular, since a nonzero null vector would contradict the norm bound \(q<1\).
Thus \(A\) is nonsingular and \(\Phi(\theta_*)=0\).

Equations (5) and (6) now supply 9840 distinct, strictly interior selected roots, with the cut cell empty, and the indicator (1) satisfies all seven polynomial trace equations simultaneously.
The constant trace difference is automatically one from the degree count.
The remaining factor \((t-s)^2\) is positive at every pole and at \(-2\), since \(s\) is a nonintegral rational and \(B\) is monic integral.
The associated real monic polynomial
\[
       Q_*(t)=(t-s)^2\prod_{i\ne1991}(t-u_i(\theta_*))
\]
has exactly the prescribed root-to-pole geometry.
Applying the sign count from [C882v8](../claims/Yin_C_G0882_v8.md#quadratic-signs) in reverse, positivity of \((b_j-s)^2\) and the fixed signs of \(F(b_j)/B'(b_j)\) give the prescribed positive-then-negative residue signs.
Its seven trace differences give the real Laurent coefficients \((2,3,4,7,10,18,27)\) of \(Q_*/(tB)\) through order seven.
All its trace roots lie in \((-2,2)\), so its complete reciprocal lift has Mahler measure one as a real-coefficient polynomial.
This is a genuine root configuration, not merely a feasible fractional-occupancy vector, but it is still outside the original integer and norm constraints.

<a id="endpoint-value"></a>
## The endpoint-value constraint that this configuration fails

The original branch requires \(U=-Q(-2)/B(-2)=1\), not just the sign \(U>0\).
For the actual terminal-interval configuration above,
\[
 U=\frac{(2+s)^2}{2+c}
       \prod_{i\ne1991}\frac{2+u_i}{2+x_i},
\]
and therefore
\[
 \log U=2\log(2+s)-\log(2+c)
       -\int_{-2}^2\frac{w(t)}{2+t}\,dt.
 \tag{7}
\]
The integral is finite because the first selected root is strictly above \(-2\).
Equation (7) is not one of the seven polynomial moment constraints.
In particular, satisfying those polynomial equations and the strict root geometry does not certify the required endpoint value.

A single additional 128-bit evaluation enclosed (7) over the same entire parameter box \(X\), without adding an equation or changing any parameter.
It returned
\[
       \log U\in[-3.798\pm2.68\cdot10^{-4}],\qquad
       U\in[0.02241\pm8.70\cdot10^{-6}],
\]
so the rigorous coarse consequence is \(0.022<U<0.023\), excluding \(U=1\).
These enclosures contain the exact solution \(\theta_*\) because they cover its whole certified box.
The model has the correct strict endpoint sign, but it demonstrably fails the original endpoint value.
Moreover \(s=-15/16\) cannot be a root of a monic integer polynomial, so \(Q_*\) is not an integer-polynomial witness; the prescribed resultant has not been imposed or certified either.

The outcome separates three requirements that must not be conflated: the seven polynomial moments, the genuine oriented interval structure, and the original endpoint value.
The first two are now simultaneously compatible for this single residual triple; the present certified configuration fails the third.
No conclusion about a different real interval configuration satisfying \(U=1\), or about the other four residual triples, follows.

<a id="bounded-reproduction"></a>
## Reproduction and actual finite scope

The optional numerical proposal was limited to the fixed seven coarse parameters, at most eight Newton iterations and 60 seconds.
It converged in three iterations; the largest parameter correction was about \(0.00565641\).
The fixed 128-bit, radius-\(2^{-16}\) existence certificate completed successfully, as did the separately authorized same-box endpoint diagnostic.
There was no scan of conductors, degrees, atomic positions, radii, precisions or additional residue triples.

The default verifier requires Python and `python-flint`; it does not require NumPy or SciPy.
From the repository root one can run the installed dependency environment with:

```powershell
uv run --no-project --with sympy --with scipy --with python-flint python -B mathematics/computations/programs/Yin_J_G0151/terminal_intervals.py
```

The default executes the fixed existence certificate and endpoint diagnostic.
The `--endpoint` option runs only the latter on the same box.
The `--propose` option uses NumPy for the bounded numerical proposal; it is not a proof premise or a replacement for the fixed certificate.
The native program stores all necessary numerical proposal data, constructs the actual poles directly, and needs no generated-output file.
