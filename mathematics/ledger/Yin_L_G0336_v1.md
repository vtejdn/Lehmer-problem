### 2. Forced coordinates preserve the full original central normalization

Let X be ANY integer d-by-b matrix with columns a_j, and let mu be the law of X eta under the original digits.

    mu_I(y)=sum_v q_I(v)q_I(v-y)
             <=sum_v q_I(v)^2=mu_I(0).                  (2)

This is the existing binary-autocorrelation center maximum used in L293/L331.
It requires neither a unimodular map nor an injective binary encoding and applies to empty subsets as well.

**Lemma 1 (forced nonzero coordinates).** Suppose z is attained and there is a set F of r coordinates and fixed signs e_j in{-1,1}, j in F, such that EVERY eta in{-1,0,1}^b satisfying X eta=z has eta_j=e_j.

    mu(z)/mu(0)<=2^(-r).                                (3)

Consequently C1 holds at z whenever E(z)=z^T(XX^T)^+z<=r, and holds strictly whenever E(z)<r.

*Proof.* Put J={0,...,b-1}\F and v_F=sum_(j in F)e_j a_j.

    mu(z)=4^(-r) mu_J(z-v_F).

The full central atom includes the event that every F coordinate is zero and the J endpoint is zero, which has probability2^(-r)mu_J(0).

Every original weight, the full remaining fiber and the complete central normalization are retained.

If J is empty, its zero atom is1 and the same proof applies.

There is a usable geometric sufficient test for such coordinates, but it is only a sufficient test.
For any real linear functional ell on the output space, define

    M_ell=sum_j |ell(a_j)|,
    delta_ell(z)=M_ell-ell(z)>=0.

For every representing word one has the exact nonnegative identity

    delta_ell(z)=sum_j [|ell(a_j)|-eta_j ell(a_j)].        (4)

If |ell(a_j)|>delta_ell(z), necessarily eta_j=sign(ell(a_j)); otherwise that single summand would already be at least |ell(a_j)|.
