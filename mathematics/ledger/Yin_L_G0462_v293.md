# All finite mask maxima and the weight series of minimal relations at the plastic number

<a id="results"></a>
## Interval maxima and minimal ternary supports

For \(P=X^3-X-1\), let \(a_N\) be the maximum number of exponents in \([0,N)\) whose binary subset sums are all distinct modulo \(P\).
The [previous certificate](Yin_L_G0462_v286.md#density) gives the limiting density \(1/3\).
The exact values are \(a_N=N\) for \(0\le N\le3\) and \(a_N=\lfloor(N+5)/3\rfloor\) for every \(N\ge4\).
A minimal support is a set of exponents that supports a nonzero ternary multiple of \(P\) while every proper subset has distinct binary subset sums.
Let \(m_j\) count these supports of size \(j\) up to translation, counting the underlying sets once regardless of the possible coefficient signs.
Their [weight generating function](../claims/Yin_C_G0345_v576.md#statement) is
\[
 \sum_{j\ge0}m_j x^j=
 \frac{x^3(2+2x+x^2+2x^3-2x^4-x^5)}{1-3x+x^2-3x^3+2x^5}.
\]
It starts with \(2x^3+8x^4+23x^5+69x^6+206x^7\).

## Computing all returning carries and counting their masks

Read ternary digits from highest to lowest power, with carry \((a,b,c)\) representing \(a+bX+cX^2\).
For the plastic root \(r>1\), any carry on a returning word satisfies \(|a+br+cr^2|\le1/(r-1)<4\), by solving backward from the terminal zero.
Substitution and monotonicity give \(1.32<r<1.33\).
The test below bounds the real value by interval arithmetic in these rational endpoints and retains all triples whose interval intersects \([-4,4]\).
Reachability from zero with this relaxed test terminates after precisely 233 distinct triples, as the completed queue verifies.
Backward reachability trims them to 179 actual returning triples, including zero.
This is exact since every returning word survives and every path in the trimmed graph uses actual lattice transitions.
For a mask prefix keep all reachable nonzero returning carries up to sign; a selected bit also starts a word at the current exponent.
A first nontrivial return to zero rejects the mask, since the remaining digits can be zero, as in the [general finite graph](../claims/Yin_C_G0345_v573.md#masks).
This construction gives 49 reachable states for admissible prefixes.
The vector of maximum weights at each state, with unreachable states distinguished, repeats upon subtracting its maximum at lengths 12 and 15, the latter maximum larger by one.
Time homogeneity propagates this exact recurrence to all later lengths.

To recognize minimal supports, track the unaltered admissible prefix state and the set of admissible states produced by deleting exactly one previously selected bit.
Each selected bit permits a new deletion at that position.
If a deletion has already caused rejection, the resulting full mask has a proper dependent subset and is discarded.
Accept exactly when the entire prefix first becomes dependent on a selected bit while every one-bit deletion remains admissible.
Every proper subset lies in some one-bit deletion, which proves that this accepts precisely the minimal masks when read from the first to the last selected bit.
Require the first bit to be one and end the word at acceptance, giving one word per translation class.
The graph has 382 intermediate states before trimming, of which 106 can reach acceptance.
Partition refinement by the two labelled successors gives 27 distinct classes including the initial, accepting and rejecting classes.
For each other class its continuation series is the sum over its outgoing edges of the successor series times \(x^z\), where \(z\) is the bit.
The accepting series is one and the rejecting series is zero.
The finite [gap bound](../claims/Yin_C_G0345_v576.md#norm) off the unit circle ensures only finitely many normalized minimal words at every weight, so these path sums define formal series.
Solving the equations and weighting the required first bit gives the displayed fraction.

```python
from collections import defaultdict, deque

import sympy as sp

ZERO = (0, 0, 0)
ONE = (1, 0, 0)
REJECT = -1
ACCEPT = -2


def step(carry, digit):
    a, b, c = carry
    return (c + digit, a + c, b)


def meets_real_bound(carry):
    a, b, c = carry
    linear = (13200 * b, 13300 * b)
    quadratic = (132**2 * c, 133**2 * c)
    lower = 10000 * a + min(linear) + min(quadratic)
    upper = 10000 * a + max(linear) + max(quadratic)
    return lower <= 40000 and upper >= -40000


def backward_reachable(predecessors, targets):
    reached = set(targets)
    pending = deque(targets)
    while pending:
        state = pending.popleft()
        for previous in predecessors[state] - reached:
            reached.add(previous)
            pending.append(previous)
    return reached


# Find all exact returning carries in the enclosure.
reachable = {ZERO}
pending = deque([ZERO])
predecessors = defaultdict(set)
while pending:
    carry = pending.popleft()
    for digit in (-1, 0, 1):
        successor = step(carry, digit)
        if meets_real_bound(successor):
            predecessors[successor].add(carry)
            if successor not in reachable:
                reachable.add(successor)
                pending.append(successor)
returning = backward_reachable(predecessors, {ZERO})
assert (len(reachable), len(returning)) == (233, 179)


def admissible_successor(carries, bit):
    destinations = set()
    for carry in carries:
        for digit in range(-bit, bit + 1):
            successor = step(carry, digit)
            if successor == ZERO:
                return REJECT
            if successor in returning:
                negative = tuple(-c for c in successor)
                destinations.add(max(successor, negative))
    if bit:
        destinations.add(ONE)
    return frozenset(destinations)


def build_graph(initial, successor):
    # Nonterminal states get nonnegative IDs in discovery order.
    state_ids = {initial: 0}
    pending = deque([initial])
    transitions = []
    while pending:
        state = pending.popleft()
        row = []
        for bit in (0, 1):
            target = successor(state, bit)
            if target in (REJECT, ACCEPT):
                row.append(target)
            else:
                if target not in state_ids:
                    state_ids[target] = len(state_ids)
                    pending.append(target)
                row.append(state_ids[target])
        transitions.append(tuple(row))
    return transitions


mask_edges = build_graph(frozenset(), admissible_successor)
assert len(mask_edges) == 49

# For each length retain every reachable state's maximum, including length 15.
best_by_length = [{0: 0}]
for length in range(1, 16):
    next_best = {}
    for state, weight in best_by_length[-1].items():
        for bit, target in enumerate(mask_edges[state]):
            if target != REJECT:
                next_best[target] = max(next_best.get(target, -1), weight + bit)
    best_by_length.append(next_best)
assert best_by_length[15] == {s: w + 1 for s, w in best_by_length[12].items()}
assert all(max(best.values()) == (n if n <= 3 else (n + 5) // 3)
           for n, best in enumerate(best_by_length))


def minimal_successor(state, bit):
    intact, one_deletion = state
    deletions = {mask_edges[s][bit] for s in one_deletion}
    if bit:
        deletions.add(mask_edges[intact][0])
    if REJECT in deletions:
        return REJECT
    intact = mask_edges[intact][bit]
    if intact == REJECT:
        return ACCEPT if bit else REJECT
    return (intact, frozenset(deletions))


minimal_edges = build_graph((0, frozenset()), minimal_successor)
assert len(minimal_edges) == 382
predecessors = defaultdict(set)
for state, targets in enumerate(minimal_edges):
    for target in targets:
        predecessors[target].add(state)
live = backward_reachable(predecessors, {ACCEPT})
assert len(live - {ACCEPT}) == 106

# Merge dead states into REJECT and refine until the partition stabilizes.
trimmed_edges = {REJECT: (REJECT, REJECT), ACCEPT: (REJECT, REJECT)}
for state in live - {ACCEPT}:
    trimmed_edges[state] = tuple(target if target in live else REJECT
                                 for target in minimal_edges[state])
classes = {state: int(state == ACCEPT) for state in trimmed_edges}
while True:
    signatures = {state: (classes[state], classes[zero], classes[one])
                  for state, (zero, one) in trimmed_edges.items()}
    labels = {sig: i for i, sig in enumerate(sorted(set(signatures.values())))}
    refined = {state: labels[sig] for state, sig in signatures.items()}
    if len(labels) == len(set(classes.values())):
        break
    classes = refined
assert len(set(classes.values())) == 27

# Write one continuation equation per nonterminal class after the first bit.
representatives = {label: state for state, label in classes.items()}
excluded = {classes[0], classes[ACCEPT], classes[REJECT]}
interior = sorted(set(representatives) - excluded)
index = {label: i for i, label in enumerate(interior)}
x = sp.symbols('x')
matrix = sp.eye(len(interior))
constant = sp.zeros(len(interior), 1)
for label, row in index.items():
    for bit, successor in enumerate(trimmed_edges[representatives[label]]):
        target = classes[successor]
        if target in index:
            matrix[row, index[target]] -= x**bit
        elif target == classes[ACCEPT]:
            constant[row] += x**bit
        else:
            assert target == classes[REJECT]
first_one = classes[minimal_edges[0][1]]
series = x * matrix.inv(method='DM')[index[first_one], :].dot(constant)
expected = (x**3 * (2 + 2*x + x**2 + 2*x**3 - 2*x**4 - x**5)
            / (1 - 3*x + x**2 - 3*x**3 + 2*x**5))
assert sp.cancel(series - expected) == 0
```
