# Least common residue exponents on the 72 listed Salem inputs

<a id="benchmark"></a>
## All-prime minima and witnesses

For each polynomial \(P\) in [Mossinghoff's June 2026 table as read by J173](../computations/programs/Yin_J_G0173/least_exponents.py), let \(J(P)\) be the least positive integer \(j\) for which some odd prime \(p\nmid j\) gives at least three distinct roots of \(X^j-1\) in \(\overline{\mathbb F}_p\) that are simple roots of \(P\bmod p\).
Across all 72 inputs, the minimum is 5, attained at ranks 21 and 49, and the maximum is 97, attained only at rank 11 with witness \(p=193\).
The Lehmer polynomial at rank 1 has \(J(P)=25\) with \(p=7\).
The table gives the least prime at each rank's least exponent and the number \(s\) of common simple roots there.

Three distinct such residues lift to three distinct conjugates in a common unramified local extension, by the simple-root form of Hensel's lemma after extending the residue field.
For each lifted root \(u\), reduction gives \(v_p(u^j-1)\ge1\) in the normalization \(v_p(p)=1\).
At least two of the three lifted conjugates are multiplicatively independent: among any three one can choose two distinct nonreciprocal ones.
Under an embedding sending the first to the real Salem root greater than one, the second has modulus one, since it maps to neither the Salem root nor its inverse.
The modulus of a multiplicative relation then forces the first exponent to vanish, and the second conjugate is nontorsion.
By the [local pair estimate](../claims/Yin_C_G0345_v586.md#statement), each such witness bounds the number of rational-output dilations of a fixed eligible list of length \(k\) by \(4kJ(P)\).
The minimum here refers to the three-simple-root criterion.

## Certifying the least exponent over all odd primes

For each divisor \(k\mid j\), compute the integer \(R_k=|\operatorname{Res}(P,\Phi_k)|\).
It is nonzero because no conjugate of the Salem number is a root of unity.
A prime dividing none of these integers gives no common root, by the cyclotomic factorization of \(X^j-1\) and the criterion for vanishing of the resultant over a field.
For each odd prime divisor of their product outside the divisors of \(j\), form \(G=\gcd(P,X^j-1)\) modulo \(p\).
Since \(p\nmid j\), the polynomial \(G\) is squarefree, and the required count is \(\deg(G/\gcd(G,P'))\).
The calculation tests all possible primes for each smaller exponent, with \(j=1,2\) excluded by degree, and stops at the least witnessing prime of the first successful exponent.
All 72 searches finish before the program's cap of 120.

The following calculation ran from the repository root with Python and SymPy 1.14.0, using J173's original table reader.
For every resultant used, it checks that its factorization reconstructs the integer and that all reported prime factors lie in the deterministic 64-bit range of the primality test.

```python
from collections import Counter
from math import prod
from functools import cache
from pathlib import Path
from runpy import run_path
import sympy as sp

root = Path('mathematics/computations/programs/Yin_J_G0173')
source_rows = run_path(str(root/'least_exponents.py'))['source_rows']
x = sp.Symbol('x')

@cache
def cyclotomic(n):
    return sp.Poly(sp.cyclotomic_poly(n, x), x, domain=sp.ZZ)

def first_witness(half, limit):
    P = sp.Poly.from_list(half + half[-2::-1], gens=x, domain=sp.ZZ)
    prime_factors = {}
    for j in range(3, limit + 1):
        divisors = sp.divisors(j)
        for k in divisors:
            if k not in prime_factors:
                R = abs(int(P.resultant(cyclotomic(k))))
                assert R > 0
                factors = sp.factorint(R)
                assert prod(p**e for p,e in factors.items()) == R
                assert all(p < 2**64 and sp.isprime(p) for p in factors)
                prime_factors[k] = set(factors)
        candidates = sorted(set.union(*(prime_factors[k] for k in divisors)))
        for p in candidates:
            if p == 2 or j % p == 0:
                continue
            A = P.set_modulus(p)
            B = sp.Poly(x**j-1, x,modulus=p)
            G = A.gcd(B)
            simple = G.exquo(G.gcd(A.diff()))
            if simple.degree() >= 3:
                return j, int(p), simple.degree()
    raise AssertionError('Increase witnessed search length')

rows = [(rank, *first_witness(half, 120)) for rank,d,s,half in source_rows()]
print(rows)
print(sorted(Counter(j for rank,j,p,g in rows).items()))
```
