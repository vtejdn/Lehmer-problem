## Rational factors containing the dyadic residue

Let \(s\equiv2\pmod3\), \(a=3^t\) with \(t\ge1\), and put \(D_a(X)=X^{2a}+X^a+1\) over \(\mathbb F_2\).
The [paired-offset calculation](../claims/Yin_C_G0345_v553.md#statement) selects a rational irreducible factor on each side by divisibility of its reduction by \(D_a\).
For each row below, complete factorization over the integers gives only \(X+1\) and the selected factor, both simple.
The signed columns refer to \(b=as^3-1,as^3+1\), respectively.

| \(s\) | \(a\) | \(b_-\) | \(b_+\) | \(\deg P_-\) | \(\deg P_+\) |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 5 | 3 | 374 | 376 | 388 | 390 |
| 5 | 9 | 1124 | 1126 | 1168 | 1170 |
| 5 | 27 | 3374 | 3376 | 3508 | 3510 |
| 5 | 81 | 10124 | 10126 | 10528 | 10530 |
| 8 | 3 | 1535 | 1537 | 1558 | 1560 |

The short-offset pair \((s,a)=(5,81)\), \(b=2,4\), has the same factor pattern, with respective selected degrees \(406,408\).
Here the dyadic residue itself has degree \(162>22s\).
These computations extend the [earlier two-offset sample](Yin_L_G0462_v282.md#sections), in which every first exponent at seed degree five was two.
In every cubic row listed, \(\deg P=as+b-1\), so it accounts for the full noncyclotomic degree.
The [asymptotic degree criterion](../claims/Yin_C_G0345_v548.md#statement) still leaves the behavior at growing seed degree open.

## Integer factorizations and the residue test

A collaborating agent for Sheng Yin computed the complete integer factorizations with python-flint 0.9.0, checked the product against the input, and identified the marked factors by polynomial division in \(\mathbb F_2[X]\).
The following code tests both the integer and the residue calculations and prints the cyclotomic orders, the selected degree and the degrees of any other nontorsion factors.

```python
from flint import fmpz_poly as Z, nmod_poly as M
x = Z([0, 1])
z = M([0, 1], 2)
for s, a, offsets in [(5, 3, (374, 376)), (5, 9, (1124, 1126)),
                      (5, 27, (3374, 3376)), (5, 81, (10124, 10126)),
                      (8, 3, (1535, 1537)),
                      (5, 81, (2, 4))]:
    marker = z**(2*a) + z**a + 1
    assert marker.factor()[1] == [(marker, 1)]
    for b in offsets:
        f = x**(a*s+b) + x**(a*s+b-a) - x**(a*s) - x**b + x**a + 1
        unit, factors = f.factor()
        product = Z([int(unit)])
        cyclotomic, selected, other = [], [], []
        for p, e in factors:
            product *= p**e
            order = int(p.is_cyclotomic())
            residue = M([int(c) for c in p.coeffs()], 2)
            if not residue % marker:
                assert not order and e == 1
                selected.append(p.degree())
            elif order:
                cyclotomic.extend([order] * e)
            else:
                other.extend([p.degree()] * e)
        assert product == f and len(selected) == 1
        print(s,a,b,sorted(cyclotomic),selected[0],sorted(other),flush=True)
```

## A finite search for a second noncyclotomic factor

For the pairs and bounds in the following code, take every \(1\le b\le b_{\max}\) with \(\gcd(a,b)=1\) and \(as+b\) odd.
Complete integer factorization found exactly one noncyclotomic irreducible factor, counted with multiplicity, in each of the 1,954 sections.
The coordinating researcher reran both code blocks with python-flint 0.9.0, recovered the twelve listed degrees and reproduced the count of 1,954.
Cyclotomic indices can vary in this search.
Only the twelve individual factorizations above also have their exact cyclotomic orders and marked degrees reported here.

```python
from math import gcd

ranges = [(s, 3, 720) for s in (5, 8, 11, 14)]
ranges += [(s, 9, 720) for s in (5, 8, 11)]
ranges += [(s, 27, 360) for s in (5, 8)] + [(5, 81, 100)]
count = 0
for s, a, bound in ranges:
    for b in range(1, bound + 1):
        if (a*s + b) % 2 == 0 or gcd(a, b) != 1:
            continue
        f = x**(a*s+b) + x**(a*s+b-a) - x**(a*s) - x**b + x**a + 1
        unit, factors = f.factor()
        assert sum(e for p, e in factors if not p.is_cyclotomic()) == 1
        count += 1
assert count == 1954
```
