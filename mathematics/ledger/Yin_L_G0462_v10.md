# Exact-prefix supply, whole-measure control and the failed first cut

<a id="scope"></a>
## What this strategy changes

The [full affine coefficient chart](Yin_L_G0462_v9.md#affine-moments) separates integer supply from a chosen square class.
Its [first verified input](../computations/programs/Yin_J_G0155/readme.md#factorization-measure) has complete measure about 2.620597651610943, so feasibility of the first two moments does not itself give a small-measure mechanism.
The next question is whether a sufficiently long exact prefix can control the complete measure before the remaining coefficients are chosen.

The complete mathematical statement and proof are in [C881v3](../claims/Yin_C_G0881_v3.md#statement), with its [independently reviewed assessment](../claims/Yin_C_G0881_v3.md#decision-odd-grid-prefix).
It uses the full odd grid and the original strict single-cut signs and endpoint, with all original factors and multiplicities.
For each \(x\in\{-2,-1,0,1,2\}\), the exact profile is
\[
                     P_{*,x}(z)=\frac{(1-xz+z^2)^2}{(1-z)^2(1+z)}.
\]
The proposed return is a whole-measure upper bound tending to one as the matching length grows.
The specific first parameters \(p=401\), three negative terminal nodes and prefix length 140 fail an exact real-positivity test.
No integer proposal, replacement parameter scan or mixed-integer computation is performed here.
This material records strategy development and its limits, not independent review or adoption of C881v3.

<a id="prefix-coordinates"></a>
## A concrete integer extension problem

Use the full odd-grid construction and conventions of [C881v3](../claims/Yin_C_G0881_v3.md#original-domain).
For \(p=2n+1\), write \(h=\sum_{i=0}^{n-1}a_iE_i\), \(C=(E_{n-1}+E_{n-2})h\bmod(E_n+E_{n-1})\), \(Q=(t-2x)(E_n+E_{n-1})+C\), and \(P=z^{n+1}Q(z+z^{-1})\).
The [exact coordinate identity](../claims/Yin_C_G0881_v3.md#prefix-coordinates) says that agreement with \(P_{*,x}\) through coefficient index \(L\), where \(2\le L\le n+1<p\), fixes exactly
\[
 a_0=x^2+2,\qquad a_i=-4x\ \text{for odd }i,\qquad
 a_i=x^2+4\ \text{for positive even }i,
                    \qquad i\le L-2.
\]
All later coordinates remain unrestricted integers.
This uses the complete affine input domain, without a fixed square class or a prescribed norm.
At \(x=0\), the separate \(N=6\) test fixes only the first extra even coordinate \(a_2=4\), corresponding to matching through index 4.
At \(x=-1\), matching through that same index requires \(a_2=5\), hence \(N=8\), not \(N=7\).
Neither a short matching input nor an input with a different third moment supplies evidence for longer extension.

The [reverse upper bound](../claims/Yin_C_G0881_v3.md#whole-measure-upper) removes the need to guess the exterior-root cost independently for each completion:
\[
 M(P)\le(8\lfloor L/2\rfloor+8)^{2/\lfloor L/2\rfloor}.
\]
It treats both real residual roots and a nonreal conjugate pair, including multiplicity, and uses the complete identity \(M(P)=\rho_1\rho_2\).
Its [baseline Newton calculation](../claims/Yin_C_G0881_v3.md#newton-baseline) explicitly requires \(j<p\), where the full odd-grid lift has Newton sum \(-1\).
No degree factor remains in the upper estimate.

## The first proposed parameters fail over the reals

The first proposal was \(p=401,\ n=200,\ \kappa=3,\ x=0,\ L=140\).
The proposed upper bound would be \(568^{1/35}<6/5\).
However, [C881v3's exact positive test](../claims/Yin_C_G0881_v3.md#fixed-compatibility-test) proves that these cut parameters cannot support even a real coefficient vector matching through index 83.
The rational separator is \(c=-799/400\), and a degree-40 test polynomial gives a strictly negative value where the sign chamber requires strict positivity.
Thus matching length 140 is excluded before integrality, the endpoint condition or a norm budget is considered.

This is the bounded first test's substantive outcome.
The complete convolution formulas and rational arithmetic certificate belong to C881v3.
No MILP should be run at these rejected parameters, and this failure is not evidence against all growing-cut extensions.

<a id="growing-scale"></a>
## Length and cut must grow on compatible scales

For \(x=0\), the [compatibility inequality](../claims/Yin_C_G0881_v3.md#prefix-cut-compatibility) limits the prefix using a positive polynomial.
At the angular-midpoint separator \(c=-2\cos(2\pi\kappa/p)\), its [asymptotic consequence](../claims/Yin_C_G0881_v3.md#growing-scale) is
\[
 \limsup\frac{\kappa L}{p}\le\frac{\sqrt3}{\pi}
 \qquad\text{when }L\to\infty,\ \kappa/p\to0.
\]
A cut staying away from \(-2\) therefore cannot support unbounded matching lengths.
For \(\kappa/p\asymp1/\log p\), the necessary bound permits at most \(L=O(\log p)\).
It alone does not exclude \(L\asymp\log p\) with a sufficiently small constant.
Actual noncyclotomic integer extensions at that length would still give the slow but sufficient rate \(\log M(P)=O(\log\log p/\log p)\to0\).
No such extensions are established.

Fixed \(\kappa\) is not an automatic alternative.
The existing [positive-resolvent estimate](Yin_L_G0464_v1.md#moving-gap-mesh) gives bounded total residue variation on bounded-measure inputs with a nonreal exceptional pair when the number of negative terminal poles is fixed.
For the full odd grid, let \(c_{\rm ar}=(b_{n-\kappa}+b_{n-\kappa+1})/2\) be the arithmetic midpoint used by that estimate.
The ratio \((2+c_{\rm ar})/(b_{n-\kappa}-b_{n-\kappa+1})\) is likewise bounded for fixed \(\kappa\), so the same endpoint estimate has that implication here.
The [bounded-variation gap](../claims/Yin_C_G0880_v1.md#statement) then obstructs a shrinking positive sequence within that fixed-block nonreal branch.
This observation does not extend the cited estimate to every real-quadratic branch or assert a new universal fixed-block theorem.
Any proposed all-conductor supply must respect both this existing obstruction and the new length constraint.

<a id="actual-count-obligation"></a>
## The remaining obligation is a positive count of actual integer completions

For the count reduction, require \(L\ge3\), so \(a_0=x^2+2\) and \(a_1=-4x\).
Fix one of the five integer profiles, an odd conductor, a cut separator \(c\), and the corresponding required prefix.
Use the full-grid weights and residues from C881v3.
Inside the strict sign chamber,
\[
 \mu_j=(b_j-c)\nu_jh(b_j)>0,\qquad
 \sum_j\mu_j=a_1-ca_0=-4x-c(x^2+2)=:H_x(c).
\]
If \(H_x(c)\le0\), the strict sign chamber is empty.
Assume \(H_x(c)>0\).
The [general orthogonality proved in C881v3](../claims/Yin_C_G0881_v3.md#prefix-cut-compatibility) and \(|E_i(b_j)|\le i+1\) give a finite covering box: if \(0<\delta<\min_j|b_j-c|\), then
\[
                |a_i|<H_x(c)(i+1)/\delta.
\]
Indeed, \(\sum_j\nu_j|h(b_j)|=\sum_j\mu_j/|b_j-c|<H_x(c)/\delta\), and \(a_i=\sum_j\nu_jh(b_j)E_i(b_j)\).
This is the all-conductor form of the [finite-box mechanism](Yin_L_G0462_v9.md#complete-coefficient-box); the first two prescribed moments are essential for the displayed total mass.
For \(x=0\) this specializes to \(H_0(c)=-2c\) and therefore requires \(c<0\).
The case \(L=2\) belongs to the upper theorem but is not included in this count reduction.

If the required integer prefix lies outside this covering box, its strict sign count is already zero.
Otherwise fix those coordinates and put the remaining integer coordinates under the uniform law on that finite box.
Every label is an actual integer polynomial through the original construction.
Let \(N_{p,\kappa,L,x}^{+}\) count labels satisfying all strict signs, the strict endpoint, and the condition that the complete lift is not a product of cyclotomic polynomials.
All multiplicities are included.
The equivalence of this last condition with \(M(P)>1\), for these monic integer polynomials with constant coefficient one, uses Kronecker's theorem exactly as retained in [Smy08-U001](../audits/literature/Smy08/Yin_U001.md#smy08-height-normalization), printed p.322.
Only the established theorem statement is reused, not a claimed new review of its original proof.

An exact complete-factor certificate or another complete certificate of \(M(P)>1\) is still required for every returned candidate.
Cyclotomic completions have measure one and contribute zero to \(N_{p,\kappa,L,x}^{+}\).
A necessary norm budget may be used as an explicitly stated subsequent filter, but it is not substituted for the integer domain or for positivity of this count.

If \(N_{p,\kappa,L,x}^{+}>0\) and the proved upper bound is below \(1+\varepsilon\), the strict-shell probability under this finite law is positive.
If such positive counts exist at unbounded matching lengths, every \(\varepsilon>0\) has an actual integer model with positive probability of \(1<M(P)<1+\varepsilon\).
A countable mixture assigning positive weights to the corresponding finite laws has the same support implication.
These are conditional consequences of actual positive counts; no continuous small-ball probability or local representation density establishes those counts.

The next arithmetic question is therefore a compatible growing-cut family with noncyclotomic integer prefix extensions.
The upper estimate makes its complete-measure return explicit, while the failed first test shows that real compatibility must precede integer proposal generation.
Neither a new conductor scan nor a new prefix length is selected here.
