# Exact factorization of twelve six-term sections at cubic offsets

<a id="sections"></a>
## The noncyclotomic quotient at both offsets

For \(b=as^3\pm1\), let \(N=as+b\) and take the monic associate of the [six-term section](../claims/Yin_C_G0345_v544.md#statement),
\[
 G(T)=T^N+T^{N-a}-T^{as}-T^b+T^a+1.
\]
For each of the twelve sections below the complete factorization in \(\mathbb Z[T]\) consists of the indicated cyclotomic polynomials \(\Phi_j\) and a single further irreducible polynomial of the indicated degree, all with multiplicity one.
The formula for \(G\) and the list of indices determine the latter polynomial exactly as \(G/\prod_j\Phi_j\).

At \(s=3\) the indices also follow from the [complete cubic-seed classification](Yin_L_G0462_v172.md#cyclotomic).
For \((s,a)=(4,2)\), the [classification at every primitive second exponent](Yin_L_G0462_v230.md#rows) already gives irreducibility of the noncyclotomic quotient.
The [three earlier trace-polynomial certificates](Yin_L_G0462_v190.md#criterion) use different parameter pairs and a modular argument.
These twelve exact quotients provide finite comparisons for the [conditional single-factor prediction](../claims/Yin_C_G0345_v544.md#statement); they leave open whether reducible noncyclotomic quotients or critical factors occur along sequences with both \(a,s\to\infty\).

## Reproducing the integer factorizations

A collaborating agent for Sheng Yin computed the complete integer factorizations using SymPy 1.14.0 and separately checked the reported cyclotomic indices by Ramanujan sums.
The following code reproduces the table by recognizing the cyclotomic factors in each complete factorization and multiplying all factors back out.
The recognition bound of 14 is specific to this table: an unrecognized cyclotomic factor of any order triggers the assertion on the remaining factor.

```python
import sympy as sp

x = sp.Symbol("x")
indices = {sp.Poly(sp.cyclotomic_poly(j, x), x): j for j in range(1, 15)}
for s, a in [(3, 2), (3, 3), (3, 4), (4, 2), (4, 3), (5, 2)]:
    for shift in (-1, 1):
        b = a * s**3 + shift
        n = a * s + b
        g = sp.Poly(x**n + x**(n-a) - x**(a*s) - x**b + x**a + 1, x)
        content, factors = g.factor_list()
        assert content == 1 and all(k == 1 for _, k in factors)
        assert sp.prod(q**k for q, k in factors) == g
        orders = sorted(indices[q] for q, _ in factors if q in indices)
        other = [q for q, _ in factors if q not in indices]
        assert len(other) == 1 and not other[0].is_cyclotomic
        print(s, a, b, orders, other[0].degree())
```
