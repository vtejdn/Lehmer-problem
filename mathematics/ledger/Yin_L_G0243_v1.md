### 2. A safe exact state reduction for the finite computation

Write q=(q_0,q_1,q_2,q_3)=(h_(j-4)...,h_(j-1)).
Its actual transition is

    S_e(q)=(q_1,q_2,q_3,e-q_0+q_1+q_2+q_3).

For every root gamma of P, define

    L_gamma(q)=-q_0/gamma+(gamma^2-gamma-1)q_1
                            +(gamma-1)q_2+q_3.

Directly using P(gamma)=0 gives L_gamma(S_e q)=gamma L_gamma(q)+e.

    |L_beta(q)|<1/(beta-1),

The first bound uses the finite remaining suffix; the second uses the finite elapsed prefix.
