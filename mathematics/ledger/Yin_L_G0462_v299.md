# The greatest period-fourteen Fourier coefficient can miss a conductor factor

<a id="comparison"></a>
## Golden ratio and quartic Salem unit at the same period

Let \(R=\mathbb Z[\alpha]\), \(B=R/(\alpha^{14}-1)R\), and let the amplitude of an additive character be \(A(\chi)=\prod_{k=0}^{13}|(1+\chi(\alpha^k))/2|\).
Call the character full if its kernel contains no nonzero ideal of \(B\), so its conductor in \(R\) is exactly \((\alpha^{14}-1)R\).
For the golden ratio the largest nontrivial amplitude occurs only at full characters.
For the quartic Salem unit of minimum \(P=X^4-X^3-X^2-X+1\), **every maximizer factors through the period-seven quotient**, while the maximum at full characters is less than one third of the nontrivial maximum.
The latter ratio follows from the following rational enclosures of the maxima for the indicated character classes.

| Minimum | Character components | Maximum amplitude |
| --- | --- | --- |
| \(X^2-X-1\) | Exactly one nonzero | \((0.00164568,0.00164569)\) |
| \(X^2-X-1\) | Both nonzero | \((0.04164959,0.04164966)\) |
| \(P\) | Only the characteristic-three component | \(2^{-14}\) |
| \(P\) | Only the characteristic-thirteen component | \((0.03187338,0.03187340)\) |
| \(P\) | Both nonzero | \((0.00962201,0.00962203)\) |

For the golden ratio the quotient is \(\mathbb F_{29}\times\mathbb F_{29}\), with \(\alpha=(6,24)\).
For the Salem example it is \(\mathbb F_{169}\times\mathbb F_3\), with \(\alpha=(u,-1)\), where \(u^2+6u+1=0\) over \(\mathbb F_{13}\).
Indeed these residue maps are surjective by the Chinese remainder theorem, their images satisfy \(\alpha^{14}=1\), and their sizes respectively equal the absolute resultants \(841\) and \(507\) of the minima with \(X^{14}-1\).
The resultants can be computed as \(|\det(C^{14}-I)|\) with the companion matrix \(C\).
In the second example \(X^2+6X+1\) has nonsquare discriminant \(6\) modulo 13, and divides \(X^7-1\) modulo 13, with \(u\ne1\).
Thus \((u,-1)^7=(1,-1)\), giving the asserted period-seven quotient.
On a field product a character is full precisely when each field component is nontrivial, since a nonzero ideal contains a field factor.
These quotients are taken in the generated order, as required by the [residue-field restriction example](Yin_L_G0462_v298.md#order).

## Rational interval verification

For the golden ratio take all pairs \(0\le i,j<29\), put \(q=29\), and use phase numerators \(z_k=i6^k+j24^k\pmod {29}\).
For the Salem unit take \(0\le i,j<13\), \(0\le c<3\), and put \(q=39\).
On the basis \(1,u\), the characteristic-thirteen linear functional takes values \(w_0=i,w_1=j\), giving \(w_{k+2}=-6w_{k+1}-w_k\pmod {13}\).
Then \(z_k=3w_k+13(-1)^k c\pmod {39}\).
The following standard-library Python code gives rational endpoints before rounding each displayed interval outward.
The alternating Taylor bounds use \(3.1415926<\pi<3.1415927\) and monotonicity of cosine up to \(\pi/2\).

```python
from fractions import Fraction
from math import factorial, prod


def cosine_boxes(q):
    def taylor(x, degree):
        return sum((-1)**k * x**(2*k) / factorial(2*k)
                   for k in range(degree + 1))

    boxes = []
    for j in range(q):
        t = Fraction(min(j, q-j), q)
        low = Fraction(31415926, 10**7) * t
        high = Fraction(31415927, 10**7) * t
        boxes.append((max(0, taylor(high, 5)), min(1, taylor(low, 6))))
    return boxes


def records(q):
    if q == 29:
        for i in range(29):
            for j in range(29):
                yield (bool(i), bool(j)), [(i*6**k+j*24**k) % 29 for k in range(14)]
    else:
        for i in range(13):
            for j in range(13):
                w = [i, j]
                for k in range(12):
                    w.append((-6*w[-1]-w[-2]) % 13)
                for c in range(3):
                    yield (bool(i or j), bool(c)), [(3*w[k]+13*(-1)**k*c) % 39 for k in range(14)]


for q in (29, 39):
    boxes = cosine_boxes(q)
    maxima = {}
    for components, word in records(q):
        bounds = tuple(prod(boxes[j][side] for j in word) for side in (0, 1))
        previous = maxima.get(components, (0, 0))
        maxima[components] = tuple(map(max, zip(previous, bounds)))
    print(q, maxima)
```

Both outcomes concern one fixed period and give no rate as the period tends to infinity.
