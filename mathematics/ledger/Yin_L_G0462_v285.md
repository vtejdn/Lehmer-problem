# Exact unrestricted thresholds for ternary relations through cardinality eleven

<a id="thresholds"></a>
## The first eleven thresholds

Let \(b_N=\min_P a_N(P,1)\), where \(P\) ranges over the monic minimal polynomials of all nontorsion algebraic units and \(a_N\) is the largest size of a mask of exponents in \([0,N)\) whose binary subset sums are distinct modulo \(P\).
For the [unrestricted threshold](../claims/Yin_C_G0345_v572.md#statement), \(R_1(t)\) is the last \(N\) with \(b_N\le t\).
Exact enumeration gives
\[
 R_1(1)=1,\qquad R_1(t)=3t-3\quad(2\le t\le11).
\]
In the equivalent interval formulation, \(b_1=1\) and \(b_N=\lfloor(N+5)/3\rfloor\) for \(2\le N\le31\).
The golden-ratio polynomial \(X^2-X-1\) attains the minimum for \(1\le N\le5\), and the plastic polynomial \(X^3-X-1\) attains it for \(6\le N\le31\).
Both are irreducible by the rational root test and have a real root above one.

This linear pattern must change eventually.
The [degree-ten Lehmer polynomial](../audits/literature/MRW08/Yin_U001.md#degree) has a unique exterior root, real and between one and \(6/5\) by substitution at the two endpoints.
Its [upper density bound](../claims/Yin_C_G0345_v570.md#statement) is at most \(\log(6/5)/\log 2<1/3\), while the reported linear pattern would have limiting density \(1/3\).
For the plastic polynomial itself, writing \(r>1\) for the positive root gives \(r^3=r+1>2\), so every third exponent gives distinct subset sums by domination of the smaller powers.
The finite upper certificate at \(N=30\) and subadditivity therefore give \(1/3\le D_1(X^3-X-1)\le 11/30\).

## Exhausting the exceptional minimal polynomials

To prove \(b_N\ge t\), first test the consecutive mask \(\{0,\ldots,t-1\}\).
Failure means that \(P\) divides a nonzero polynomial on that mask with coefficients in \(\{-1,0,1\}\).
Remove the initial power of \(X\) and normalize the leading sign to obtain a monic ternary polynomial of degree less than \(t\) and constant term \(\pm1\).
Factor every such polynomial over the integers and retain its noncyclotomic irreducible factors.
Replacing \(X\) by \(-X\) preserves all ternary supports, and taking the monic reciprocal reflects the support in \([0,N)\), so one representative suffices for each orbit under these two operations.
For \(t=1,\ldots,12\), the successive numbers of exceptional orbits are
\[
0,0,1,4,15,44,139,417,1303,3970,12342,37936.
\]
For each exceptional representative the computation finds an admissible \(t\)-element mask at the first \(N\) of the proposed interval.
At its last \(N\) it exhausts the \((t+1)\)-element masks for the indicated witness and finds none admissible.
Both bounds cover every intermediate \(N\) by monotonicity.

Compute the coordinate vectors of \(1,X,\ldots,X^{N-1}\) modulo \(P\) in the monomial basis.
Let \(H\) be the maximum over the coordinates of the sum of absolute values of that coordinate over all these vectors.
Encoding a vector \((c_i)\) by \(\sum_i c_i(2H+1)^i\) detects equality of binary subset sums exactly, since a ternary difference has all coordinates bounded by \(H\) and successive reduction modulo \(2H+1\) detects its first nonzero coordinate.
The search extends a mask precisely when adding the next encoded power gives a translate of its current sums disjoint from the previous sums.
Translating the first exponent to zero preserves admissibility because \(X\) is a unit modulo \(P\).

A collaborating agent for Sheng Yin obtained the finite values by integer arithmetic with Python 3.14 and python-flint 0.9.0 on November 20, 2026.
The following code reproduces the endpoint checks, using coefficient lists in ascending order.

```python
from itertools import product
from flint import fmpz_poly


def orbit(p):
    q = tuple(a * (-1)**(len(p)-1-i) for i, a in enumerate(p))
    return min(p, q, *(tuple(a*f[0] for a in reversed(f)) for f in (p, q)))


def exceptions(t):
    factors = set()
    for d in range(1, t):
        for middle in product((-1, 0, 1), repeat=d-1):
            for c in (-1, 1):
                f = fmpz_poly([c, *middle, 1])
                for g, _ in f.factor()[1]:
                    if not g.is_cyclotomic():
                        factors.add(orbit(tuple(map(int, g.coeffs()))))
    return factors


def weights(p, n):
    v = [1] + [0] * (len(p)-2)
    columns = []
    for _ in range(n):
        columns.append(v)
        v = [a-v[-1]*b for a, b in zip([0]+v[:-1], p)]
    base = 1 + 2*max(sum(map(abs, row)) for row in zip(*columns))
    return [sum(a*base**i for i, a in enumerate(v)) for v in columns]


def exists(p, n, t):
    w = weights(p, n)

    def extend(start, need, sums):
        if need == 0:
            return True
        for j in range(start, n-need+1):
            new = {s+w[j] for s in sums}
            if sums.isdisjoint(new) and extend(j+1, need-1, sums | new):
                return True
        return False

    # Translate the first selected exponent to zero.
    return t <= n and extend(1, t-1, {0, w[0]})


golden, plastic = (-1, -1, 1), (-1, -1, 0, 1)
intervals = [(1, 1, 1, golden), (2, 3, 2, golden), (4, 5, 3, golden),
             (6, 6, 3, plastic)]
intervals += [(3*t-5, 3*t-3, t, plastic) for t in range(4, 12)]
intervals.append((31, 31, 12, plastic))
for first, last, t, witness in intervals:
    candidates = exceptions(t)
    assert all(exists(p, first, t) for p in candidates)
    assert exists(witness, first, t) and not exists(witness, last, t+1)
    print(first, last, t, len(candidates), flush=True)
```
