# FW03

The [retained journal article](../../../literature/pdf/FW03.pdf) uses printed pp. 335–378, starting on PDF page 1 of the [author's copy](https://www.math.ucdavis.edu/~fannjiang/home/papers/dissipation.pdf).
Equations (17)–(18) on printed p. 346 (PDF page 12) give the norm on the mean-zero space as an optimization over integer characters.
Theorem 3 on printed p. 348 (PDF page 14) gives the small-noise asymptotic for a fixed diagonalizable ergodic automorphism using its minimum entropy per dimension among rational irreducible blocks.
