# CDT24 source and edition notes

Yin's [inspection of the integral-germ threshold](Yin_U001.md#cdt24-u001) uses Calegari, Dimitrov and Tang's [220-page author-hosted manuscript](https://www.math.uchicago.edu/~fcale/papers/L2chi.pdf).
The inspected printed page labels coincide with the one-based PDF positions cited in that unit.
The [arXiv record](https://arxiv.org/abs/2408.15403) identifies v2 dated 16 September 2024 and describes 218 pages; equivalence with the inspected author manuscript has not been established.
The author directory's file modification time is not an established manuscript version date.
The [contents transcription](../../../literature/contents/CDT24--author.md) belongs to the inspected author manuscript.
CDT25 denotes the different work *The Unbounded Denominators Conjecture* and supplies no edition identity for this source.
