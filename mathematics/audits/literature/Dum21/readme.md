## Concrete source limitations relevant to this use

- PDF25, slide XXIII: the displayed shear matrix writes offdiagonal a+mb/2.
  Direct multiplication gives am+b/2.
  The following displayed polynomial correctly has mixed coefficient b+2am.
  At m=0 the displayed matrix would already fail for generic a,b, so the erroneous matrix cannot be used as a transformation identity.
  This is a verified printed discrepancy, not merely extraction.
- PDF21, slide XIX: its definition requires strict |a|<|c| when b=|a|.
  PDF26's stopping rule instead accepts |a|=|c| and b>=0.
  In particular(a,b,c)=(1,1,-1) is accepted by that rule but excluded by the stated tie convention.
  Therefore the printed general theorem is not transferred using that definition.
- PDF38, slide XXXI: the title, computed forms and conclusion concern discriminant13, while one sentence says discriminant5.
  The forms have discriminant13 by direct expansion.
  The search result is not evidence of a discriminant5 class-number assertion.

These scoped discrepancies suffice to prevent an unqualified theorem adoption.
