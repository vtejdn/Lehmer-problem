# Milne on the cyclotomic conductor of a quadratic field

The title page identifies J. S. Milne's *Class Field Theory*, version 4.03, dated August 6, 2020.
The next page dates the first web release (version 2.01) to August 14, 1996, which supplies the bibliography key year. [Author's course page](https://www.jmilne.org/math/CourseNotes/cft.html) · [Local author PDF](../../../literature/pdf/Mil96--v4.03.pdf) · [Edition contents](../../../literature/contents/Mil96--v4.03.md)

<a id="quadratic-conductor"></a>
Chapter V, §3, Example 3.11 on printed page 159 (PDF page 168) computes the least positive \(m\) such that \(K=\mathbb Q(\sqrt d)\) is contained in \(\mathbb Q(\zeta_m)\), for a signed squarefree radicand defining a quadratic field.
This finite integer is \(|\Delta_K|\), equal to \(|d|\) if \(d\equiv1\bmod4\) and \(4|d|\) otherwise.
Milne includes the real place in the full conductor modulus when \(d<0\).
The [finite-conductor check in R474](../../reviews/Yin_R_G0562_v474.md#finding) uses the integer part for both signs and treats the trivial field separately. [Example 3.11 in the author PDF](https://www.jmilne.org/math/CourseNotes/CFT.pdf#page=168)
