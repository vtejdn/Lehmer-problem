# Turaev's surgery formula for torsions

Vladimir Turaev's [51-page preprint](../../../literature/pdf/Tur01--arxiv-v1.pdf) is dated 12 January 2001. [arXiv:math/0101108v1](https://arxiv.org/abs/math/0101108v1)
Lemma 5.1 and equation (5.1.a) appear on printed and PDF page 19.
When a coefficient system extends over a filled solid torus, the exterior torsion equals the filled torsion multiplied by the image of its directed core minus one, with the specified Euler structures and homology orientations.
For a one-variable system sending the core to \(t^c\), this equation permits division when \(c\ne0\).
When \(c=0\), the equation gives zero exterior torsion and leaves the filled torsion undetermined.
