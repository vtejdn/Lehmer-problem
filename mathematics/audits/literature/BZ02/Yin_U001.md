# Maximum number of squares in a finite integer arithmetic progression

<a id="bz02-u001"></a>
## The uniform estimate in Theorem 1

On 2026-11-21 an agent for Sheng Yin inspected the definition of \(Q(N;q,a)\) and Theorem 1 in Section 1 on printed page 69 of the journal edition.
For integers \(q\ne0,\ a\) and a positive integer \(N\), let \(Q(N;q,a)\) count the indices \(1\le j\le N\) for which \(a+qj\) is an integer square.
Let \(Q(N)\) be the maximum over all such arithmetic progressions.
Theorem 1 bounds this maximum by \(c_1 N^{3/5}(\log N)^{c_2}\) for large \(N\), with positive absolute computable constants \(c_1,c_2\).
Increasing the first constant and using \(\log(2N)\) extends the bound to every \(N\ge1\).
The printed page also distinguishes Rudin's conjectural square-root upper bound from the proved estimate. [Edition](readme.md#edition) · [Section 1 and Theorem 1](../../../literature/pdf/BZ02.pdf#page=3)

An interval of consecutive positive indices starting at an arbitrary index has the same bound because translating the index changes only \(a\).
The theorem supplies no bound on \(a\) or \(q\) as a hypothesis.
The inspection covered the statement and the passage to translated indices.
The source completes its proof on printed page 74 using estimates for elliptic curves and a choice of counting parameter; those estimates are accepted at theorem scope. [End of the proof](../../../literature/pdf/BZ02.pdf#page=8)
