# Anomalous subvarieties

## Yin's source edition

In the [published article](../../../literature/pdf/BMZ07.pdf#page=20), Theorem 4.1 begins on printed p. 20 and continues on p. 21, corresponding to the same PDF pages.
The theorem allows torsion translates of a one-parameter subgroup.
Its application with trivial translates is in the [reciprocal-factor reduction](../../../claims/Yin_C_G0345_v236.md#source).
The [Swiss repository](https://sonar.ch/documents/174054/files/fulltext.pdf) supplies the journal edition.
