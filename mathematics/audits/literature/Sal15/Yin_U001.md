# Realizing totally real algebraic integers in finite trees

Salez's Theorem 1 states that each totally real algebraic integer is an adjacency eigenvalue of a finite tree.
The matrix is the ordinary symmetric zero-one adjacency matrix of the tree.
The theorem applies to any individual eigenvalue, with no restriction on the remaining spectrum, the number of vertices or the number of branch vertices in a representing tree. [Inspected edition, pp. 1–2](readme.md#edition)

The proof outline decomposes a tree at its root and uses the resulting rational recursion for characteristic polynomials.
For a fixed nonzero totally real integer \(\lambda\), its arithmetic step identifies the recursively generated values with \(\mathbb Q(\lambda^2)\), allowing the value that gives a tree with eigenvalue \(\lambda\).
This inspection covers the adjacency convention, the statement and the outline on pp. 1–3.
Theorem 1 is accepted as an established input at statement scope.
The detailed arithmetic proof in Section 4 has not been audited here.
