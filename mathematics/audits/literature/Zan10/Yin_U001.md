# Full-degree torsion fibers over the cyclotomic closure

<a id="zan10-u001"></a>
## Zannier's Theorem 2.1

Let \(k\) be a number field and \(k^c=k(\mu_\infty)\).
For a cover \(\pi:Y\to\mathbb G_m^r\) defined over \(k^c\), condition (PB) requires irreducibility over the algebraic closure after pullback by each multiplication map \([m]\), \(m\ge1\).
Theorem 2.1 gives a finite union of proper torsion cosets outside which every torsion point has a nonempty \(k^c\)-irreducible fiber and each preimage \(u\) has \([k^c(u):k^c]=\deg\pi\).
For \(r=1\) the exceptional union is a finite set of roots of unity for the given cover.
The theorem supplies no uniform exceptional set when the cover varies.

The cover and pullback definitions and the complete torsion fiber statement were checked in the [author's preprint](readme.md#arxiv), especially Theorem 2.1 on page 6.
The source deduces this theorem using Dvornicich and Zannier's result on cyclotomic points above torsion.
That antecedent was not independently audited.
The [application to a cubic graph with a varying multiplier](../../../ledger/Yin_L_G0462_v185.md#torsion-twists) verifies (PB) and computes the degree for each fixed pair of exponents.
