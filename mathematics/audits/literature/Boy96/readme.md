# Boyd on beta expansions for Pisot numbers

<a id="edition"></a>
## Yin's source edition

David W. Boyd's *On beta expansions for Pisot numbers* appeared in *Mathematics of Computation* 65 (1996), no. 214, pp. 841–860.
Section 2 on pp. 845–846 describes regular Pisot numbers and their defining polynomials. [Journal article](https://doi.org/10.1090/S0025-5718-96-00693-X)
The [cofactor argument](Yin_U001.md#regular-cofactor) uses that defining polynomial.
