# Cox48 source and edition notes

## Yin

Coxeter's complete contribution appears in the January 1948 *American Mathematical Monthly* on printed pages 26–28, PDF pages 30–32 of the [local issue scan](../../../literature/pdf/Cox48--january-issue.pdf#page=30). [Internet Archive microfilm](https://archive.org/details/sim_american-mathematical-monthly_1948-01_55_1/page/n29/mode/1up)
On printed page 28 Coxeter explicitly attributes the alternative proof by minimum positive perpendicular distance to L. M. Kelly. [Original page 28](https://archive.org/details/sim_american-mathematical-monthly_1948-01_55_1/page/n31/mode/1up)
The [ordinary-line argument in C345v266](../../../claims/Yin_C_G0345_v266.md#ordinary) uses this planar step after projecting its finite projective configuration to the plane.
