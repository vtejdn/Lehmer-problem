# Linowitz, McReynolds, Pollack and Thompson on arithmetic systoles

## Yin's source notes

The [journal text](../../../literature/pdf/LMPT17--published.pdf) runs from printed page 1497 on PDF page 1 to printed page 1522 on PDF page 26.
Theorem 1.1 and Corollary 1.2 on printed page 1499 count commensurability classes for each fixed invariant trace field.
Pages 1502–1503 define the volume used in this count via the norm-one group of a maximal order.

Lemma 2.1 on pages 1503–1504 supplies a finite manifold cover to which a chosen closed geodesic lifts with its original length.
Proposition 3.1 on page 1505 associates a quadratic extension of bounded relative discriminant to a class with small systole.
Page 1512 gives the parity and splitting conditions on finite ramification for an embedding of a prescribed quadratic field.
