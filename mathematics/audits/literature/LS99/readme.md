# Liebeck and Shalev on simple groups and permutation groups

## Yin's source edition

The inspected journal facsimile spans pp. 497–520 of the April 1999 issue of the *Journal of the American Mathematical Society*.
Section 1.4 defines base size on p. 499, Theorem 1.4 states the linear estimate on p. 500, and its proof runs from p. 502 through p. 504.
