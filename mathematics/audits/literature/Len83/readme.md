# Lenstra's fixed-dimensional integer programming algorithm

<a id="geometry"></a>
## The journal edition and its geometric construction

Yin's source is the 1983 journal edition in the author's publication archive, with a cover sheet preceding the article. [Journal record](https://doi.org/10.1287/moor.8.4.538) · [Author's copy](https://pub.math.leidenuniv.nl/~lenstrahw/PUBLICATIONS/1983i/art.pdf)
Section 1 on printed page 541 reduces integer feasibility to a dimension-bounded number of parallel hyperplane slices, each with one fewer integer variable. [PDF page 5](../../../literature/pdf/Len83.pdf#page=5)
Section 2, Remark (c) on printed page 544 identifies enumeration of the vertices of the polytope as a means of finding a simplex of maximum volume in fixed dimension. [PDF page 8](../../../literature/pdf/Len83.pdf#page=8)
