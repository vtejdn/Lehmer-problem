# Mahler on the discriminant

The [local facsimile](../../../literature/pdf/Mah64--reprint.pdf) comes from the 2019 *Mahler Selecta*.
It reproduces the 1964 paper from the *Michigan Mathematical Journal*, pp. 257–262. [Reprint](https://ems.press/books/dms/252/4993)
The [relative discriminant estimate](../../../claims/Yin_C_G0901_v208.md#cost) applies the Vandermonde row bound separately over each embedding of the base field and averages it using the height of the later unit.
