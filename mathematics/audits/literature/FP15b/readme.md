# Energy integrals over local fields and global height bounds

## Yin’s source edition

The [local original](../../../literature/pdf/FP15b.pdf) is [arXiv version 3](https://arxiv.org/abs/1306.3544v3), dated 11 October 2014.
In this edition, Theorem 3 on page 3 treats complete splitting over specified completions of the rationals, and Theorem 9 on page 11 treats prescribed local extensions over a number field.
The [journal edition](https://doi.org/10.1093/imrn/rnt250) uses pages 1278–1294.
