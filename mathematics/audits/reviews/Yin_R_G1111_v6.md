### Exact mass calculation

For half-degree \(n\), let \(W_b=\sum_s w_b(s)\) be a block's total weight.
Conditioned on taking the biased component, a coefficient prefix \(a\) has probability \(\prod_b w_b(s_b(a))/W_b\).
The global mixture selects uniform exploration with probability \(1/10\) and the block-product component with probability \(9/10\).
Because each prefix uniquely determines its reciprocal polynomial and the target prefixes are disjoint, the conditional next-proposal probability of a target set \(T\) is exactly
\[
H(T)=\frac{|T|}{10\,9^n}
     +\frac9{10}\sum_{a\in T}\prod_b\frac{w_b(s_b(a))}{W_b}
     =\frac{|T|}{10\,9^n}
     +\frac{9\sum_{a\in T}\prod_b w_b(s_b(a))}{10\prod_bW_b}.
\]
The source's base-nine index is the stated first-coordinate-major lexicographic index, including the degree-18 singleton.
All block weights and totals are positive, so the denominator is nonzero and the uniform contribution is a valid positive floor for a nonempty target group.
The groups are disjoint, so their probabilities sum to the whole target probability.

The source combines integer products and sums before Fraction normalization.
The independent calculation instead normalizes each selected block state as a Fraction, multiplies those probabilities separately for each prefix, and then sums over prefixes using tuple-keyed state maps.
It does not use the author's aggregate numerator or base-nine index function.
For the initial law it separately uses the coordinate probabilities \(2^{4-|k|}/46\), then adds the same uniform component.
These initial masses agree exactly with the earlier census's fixed-mixture probabilities.
